## Experience and visual direction

A peaceful 3D exploration/ambient web experience inspired by Spirited Away and Studio Ghibli paintings, with no combat or compulsory quests. A muted red two-carriage train travels an elliptical sea railway in approximately eight minutes, excluding station dwell. Soft painted skies and sea colors, warm cream lights, slow movement and restrained detail should keep attention on the view.

Players orbit the exterior, walk the interior, open doors, sit, disembark onto stations/islands, use benches and recall the train. The second carriage has Chihiro beside No-Face, with the small mouse/fly-bird companions at the window. Their geometry, most scenery and many textures are generated by JavaScript, rather than external model files.

## Architecture and module map

Static HTML/CSS/JavaScript ES modules with Three.js r170, WebGL 2 and GLSL. `dist/index.html` provides UI/import maps and `dist/main.js` assembles the scene. `dist/vendor/` contains Three.js, OrbitControls, BufferGeometryUtils and Reflector. There is no React framework, bundler, gameplay backend or cross-device synchronization.

Day/evening/night selection and Thailand GMT+7 synchronization share time transitions. Weather is clear/rain/snow/mist with automatic changes and locking. Water has reflections, shallows and train wakes; night adds stars/aurora. Control Center uses Liquid Glass styling and quality presets. Photo Mode has eight ratios, eight filters, crop/lens controls and PNG export.

## v31 state and capture behavior

The welcome screen pauses travel/input until Start/Resume, selects quality/sound and can reopen for a new journey. Local checkpoints save every five simulation seconds and on hiding/exit, restoring train position/direction, seats or station/bench position, look, door targets and snow. Invalid doorway positions recover to a safe aisle. Storage denial/corruption must not block play.

- Settings: `sea-railway-settings-v1`.
- Journey: `sea-railway-journey-v1`.
- Once-only contextual hints: `sea-railway-hints-v1`.

Quiet passengers reserve seats, board/alight at stations and yield if blocked, without quests or notification sounds. Settings → journey help exports six views (day exterior, evening first station, night aurora, interior characters, rainy window, snowy second station) in a PNG ZIP, up to 1280px long edge. It restores scene/camera/time/weather after capture. The silent 15-second clip uses canvas captureStream/MediaRecorder, up to 1280px/24fps in supported WebM/MP4; it restores the view while preserving distance travelled. Downloads stay on the player's device.

## Assets, packaging and QA boundaries

The Source ZIP and Audio ZIP share `Sea-Railway-v31/`; migration flattened only that archive wrapper into the Git repository root and retained every internal path. Original image: `dist/assets/painted-sky.png`. Original soundtrack: `dist/audio/quiet-tide.wav`, with CC0 dedication and `scripts/compose-lofi.py`. Dependencies retain their MIT headers. No external model files or blanket commercial character rights were supplied.

The standalone exporter embeds 53 modules, three CSS files and two binary assets. Game play needs a static HTTP server rooted at `dist/`; no npm dependencies need installation. Node regression tests and syntax checks are distinct from optional native GLES/Canvas checks.

The handoff's earlier CPU/native checks are historical evidence. Full desktop/mobile browser smoke testing, actual WebGL screenshots/video downloads, small-screen/200% zoom Liquid Glass, device FPS and access from another account/device were still outstanding. No separate preview URL or verified v31 full-game screenshots/clip was provided. Older Notion screenshots are explicitly pre-v30 and are not v31 QA evidence.
